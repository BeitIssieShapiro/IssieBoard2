# Project review — IssieBoard / IssieVoice / IssieCalc (2026-11-22)

Read-only review of the three apps. All findings verified in code unless marked *verify on device*.

## P0 — users are hurt now

1. **IssieVoice: chosen voice silently lost after a language switch.**
   `TTSContext.tsx` caches the last-set voice in `settings.voice`, but `TTS.setLanguage()` →
   iOS `setDefaultLanguage` overwrites the native default voice (`react-native-tts/TextToSpeech.m:156-159`)
   without clearing the cache. Repro: pick "Carmit Premium", speak, switch keyboard En → He, speak →
   system default Hebrew voice (`speak()` skips `setVoice` because it thinks Carmit is still set).
   The voice-test button in settings (`VoiceSettingsPanel.tsx:97`) desyncs the same way.
   Aggravated by `MainScreen.tsx:387`: `setTTSLanguage` is a new function every render, so that effect
   re-fires on every TTS progress event (hence the `setTimeout` "avoid infinite loop" hack).
2. **IssieVoice: speech rate & pitch are never persisted** — `useState` only; reset on every launch.
3. **IssieCalc: saved rate/pitch not applied on startup** (`CalcTTSContext.tsx:386`) — only after touching
   the slider. The comment blames a TurboModule signature issue that `patches/react-native-tts+4.1.1.patch` already fixes.
4. **No way to stop speech; repeated taps queue.** Nothing calls `stop()`; `speak()` doesn't flush.
   IssieCalc every-digit mode builds a backlog that lags behind typing.
5. **IssieVoice "Save" in the unsaved-changes alert can lose changes** (`NewSettingsScreen.tsx:169`):
   `saveRef.current?.(); onDiscard();` — on a built-in profile save opens Save-As, then `goBack()` unmounts it.
   The alert is also hardcoded English.
6. **"Symbols in Suggestions" toggle does nothing** (`GlobalSettingsPanel.tsx:631`); `FavoritesBar`
   ignores the prop; `SymbolService` (ARASAAC) is test-only.
7. **Commit `6f21143` broke 14 of 33 jest suites** (all IssieCalc readout tests): `react-native-localize`
   isn't mocked. `App.test.tsx` also fails.
8. **iOS silent switch (likely — verify on device).** Neither app calls `Tts.setIgnoreSilentSwitch('ignore')`;
   with the ringer on silent, Speak is probably mute.

## Decisions (answered 2026-11-22)

1. Auto-save → **(a)** only on `background`, only for custom profiles.
2. Tapping Speak while speaking → **stops**.
3. Symbols in Suggestions → *not decided yet*.
4. 3-second hold for IssieVoice → **no**.
5. One save model → **leave as is** (IssieVoice app settings keep saving immediately).
6. `*_ordered.json` → **don't change**.
7. Calc rounding / E-notation → *more info requested*.
8. `allowFontScaling` → **don't change**.
9. Cleanup pass → **yes**.
