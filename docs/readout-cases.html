IssieCalc — readout test sheet

Every case the automated readout suite covers, as a manual checklist. Each row is generated by replaying the keys through the real code, not written by hand, so it is what the app actually does today. Tick a row once the device matches; anything different is a regression — or a case worth adding.

You should see is what appears on the calculator's display — powers as raised exponents, roots as radicals. Internal expression is the string the app holds behind that and hands to the readout, which is what the test assertions are written against; the superscripts in the first column are a text approximation of React views, so expect the device to render them more elegantly.
